# AutoPulse — інтернет-магазин автотоварів на Ruby on Rails

Курсова робота з дисципліни «Візуальні сервісно-орієнтовані рішення та фреймворки для їх реалізації».

## Функціональність
1. Реєстрація, вхід, особистий кабінет (`has_secure_password`, bcrypt)
2. Наповнення товару через адмін-панель (CRUD товарів, категорії, залишки)
3. Кошик (зберігається в БД, працює для гостей)
4. Відгуки користувачів з оцінкою 1–5
5. Зворотний зв'язок (форма звернень + обробка в адмінці)
6. Вибір доставки (Нова пошта, кур'єр, Укрпошта, самовивіз; безкоштовно від 2000 грн)
7. Оплата товару (картка онлайн через тестовий платіжний шлюз або накладений платіж)

## Запуск
Потрібен Ruby 3.2 (на Windows — RubyInstaller «Ruby+Devkit 3.2.x (x64)»).
```bash
gem install bundler
bundle install
ruby bin/rails db:setup      # створення БД, міграції, тестові дані
ruby bin/rails server        # відкрити http://localhost:3000
```
Файл Gemfile.lock не додано свідомо: Bundler сам підбере версії гемів під вашу ОС.
